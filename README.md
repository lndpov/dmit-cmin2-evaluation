## CMIN2 是什么，和 CN2 GIA 有什么区别

CMIN2（China Mobile International Network 2）是移动推出的精品骨干线路，大约 2022 年下半年开始大量出现在 VPS 商家的套餐描述里。它的定位，粗略说就是移动版的 CN2 GIA——后者是电信独有的高端线路，CMIN2 是移动体系里对标的产品。

两条区别，记住就够了：

- **CN2 GIA**：电信自有精品线路，三大运营商用它走回程，稳定性高，晚高峰表现最好，价格也最贵
- **CMIN2**：移动精品线路，移动用户走回程体验出色，联通和电信用户通过 AS9929 等优质路由也有不错表现，价格比 CN2 GIA 低一档

说实话，移动用户选 CMIN2 回程的 VPS，性价比要比 CN2 GIA 好得多。电信用户如果预算有限，CMIN2 也不是退而求其次——它走的是真实优化路由，不是普通 163 骨干那种。
